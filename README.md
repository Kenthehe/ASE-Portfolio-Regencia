## Course Introduction
**Course:** CPELX330 — Computer Engineering Elective (Term 2, 2026–2027)  
**Institution:** National University — College of Engineering  

This repository serves as my individual portfolio for **Agentic Software Engineering and Responsible AI**. Throughout this course, I will explore how autonomous AI agents are designed, integrated into modern software architectures, and governed using Agile workflows, version control best practices, and structured risk management frameworks.

## Personal Learning Goals
* **Architect Agentic Systems:** Understand how goal-driven AI agents perceive environments, plan multi-step tasks, and safely invoke external tools or APIs compared to traditional deterministic software.
* **Apply Agile & Git Workflows:** Practice iterative development, version control discipline, and modular documentation when building and testing non-deterministic AI-enabled systems.
* **Implement Responsible AI Guardrails:** Apply principles from the NIST AI Risk Management Framework—such as least-privilege permissions, human-in-the-loop oversight, and logging—to ensure AI systems remain safe, private, and reliable.

## Reflection from Part A
Transitioning from traditional software development to Agentic Software Engineering requires a fundamental shift in mindset. Unlike rule-based programs with predictable outputs, AI agents reason probabilistically and interact dynamically with external tools, which introduces unique risks such as hallucinations, prompt injection, and cascading workflow errors. 

Key takeaways from Part A highlight that autonomy must always be paired with engineering discipline: Agile methodologies provide the iterative feedback loops needed to test and refine agent behavior, while human oversight and structured risk governance ensure that AI-enabled systems remain accountable, secure, and aligned with human intent.# ASE-Portfolio-Regencia
